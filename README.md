# Walksnail VRX Hardware Control Node (Wemos D1 Mini)
# stm32 key pad (https://github.com/Mark4Titan/key_pad)

Цей репозиторій містить прошивку для модуля **Wemos D1 Mini (ESP8266)**, який виступає в ролі інтелектуального залізничного вузла керування для цифрового FPV-відеоприймача **Walksnail Avatar VRX**. 

Пристрій автоматично комутує аналогову клавіатуру VRX за допомогою фоторезистивного вазистора (VTL5C3) та оптопари (PC817), приймаючи команди від наземного пульта або через вбудований Web-інтерфейс.

## 🚀 Основні можливості

* **Dual-Mode Control:** Паралельна робота від фізичного пульта по UART та через Wi-Fi Web-панель.
* **Smart Wi-Fi (RF Noise Protection):** Модуль автоматично тушить свій Wi-Fi через 10 секунд після старту, якщо виявляє стабільний потік пакетів (Heartbeat) від пульта. Це повністю виключає радіозавади в ефірі під час польотів.
* **Captive Portal (DNSServer):** Автоматичний перехід на сторінку керування при підключенні до Wi-Fi мережі (не потрібно вводити IP вручную).
* **Live UART Monitor:** Відображення сирого HEX-потоку, що прилітає від пульта, прямо в Web-інтерфейсі для швидкого налагодження.
* **Енергонезалежна пам'ять (EEPROM):** Динамічна таблиця конфігурації 9-позиційної матриці кнопок (ШІМ та HEX-коди) з можливістю редагування через браузер.
* **Залізобетонні таймінги:** Точна імітація аналогових переходів напруги оригінальної клавіатури Walksnail завдяки 3-фазному імпульсному алгоритму.

## 🛠 Апаратна схема з'єднання (Pinout)

| Компонент | Пін Wemos D1 Mini | Опис |
| :--- | :--- | :--- |
| **VTL5C3 (Вазистор)** | `D1 (GPIO5)` | ШІМ-керування яскравістю внутрішнього світлодіода для підбору опору. |
| **PC817 (Тригер кнопок)** | `D0 (GPIO16)` | Комутує дільник напруги вазистора на лінію `DATA` приймача (імітація натискання). |
| **PC817 (Ключ BIND)** | `D2 (GPIO4)` | Пряме замикання лінії бінду Walksnail на масу (фіксований імпульс 500 мс). |
| **Software UART RX** | `D3 (GPIO0)` | Вхід для підключення лінії `TX` від пульта керування (наприклад, ESP32-C3). |
| **Software UART TX** | `D4 (GPIO2)` | Вихід програмного UART (зарезервовано). |

> ⚠️ **Важливо:** Рідний апаратний порт `Hardware Serial (TX/RX)` залишається абсолютно вільним! Ви можете підключати плату до комп'ютера по USB для моніторингу логів на швидкості `115200` навіть під час роботи всієї системи.

## 📐 Специфікація Матриці Кнопок (Default Config)

Система з коробки ініціалізується наступною конфігурацією байтів (пакети пульта) та рівнів ШІМ:

| Індекс | Назва кнопки | Рівень ШІМ (0-1023) | HEX-пакет від пульта (3 байти) |
| :---: | :--- | :---: | :--- |
| **0** | `UP` | 5 | `46 FF 29` |
| **1** | `DOWN` | 48 | `C6 FB 27` |
| **2** | `LEFT` | 10 | `46 FB 25` |
| **3** | `RIGHT` | 21 | `B7 23 23` |
| **4** | `ENTER (OK)` | 32 | `0C FF 2B` |
| **5** | `BACK` | 90 | `C6 DD 3F` |
| **6** | `REC` | 128 | `46 DD 3D` |
| **7** | `BIND` | *Цифровий пін* | `AC FF 53` |
| **8** | `FUNC` | *Зарезервовано* | `4C FF 3B` |
| **-** | `IDLE (Пульс)`| *Ігнорується* | `C6 FF 67` |

## 💻 Інтерфейс Web-Панелі Калібрування

Коли пульт вимкнений, плата піднімає власну точку доступу.

1. Підключіться до Wi-Fi мережі: `Walksnail_Remote` (пароль: `12345678`).
2. Браузер вашого смартфона автоматично відкриє сторінку керування. Якщо цього не сталося, перейдіть за адресою `http://192.168.4.1/`.

### Доступні функції в UI:
* **OSD Joystick:** Віртуальний пульт для кліків по меню Walksnail прямо з екрана.
* **Live UART Receiver:** Показує статус сигналу з пульта. Відображає `(OK)` при натисканні або `(IDLE)` при фіксації холостого ходу.
* **Matrix Editor:** Інтерактивна таблиця, де можна змінити будь-який байт чи значення ШІМ, після чого натиснути **SAVE CONFIG MATRIX** для запису в EEPROM.

## 🧠 Логіка роботи Пакетного Комутатора

Для запобігання брязкання контактів та завад, клік по аналоговій лінії DATA виконується за алгоритмом подвійної ізоляції:
1. **Фаза 1 (Розгін):** Вазистор отримує початковий ШІМ-імпульс протягом 150 мс.
2. **Фаза 2 (Стабілізація):** ШІМ фіксується на робочому значенні кнопки, очікування 30 мс, поки фоторезистор вийде на режим.
3. **Комутація:** Вмикається цифровий тригер `PIN_TRIGER` (PC817) і замикає стабільний опір на VRX на 250 мс.
4. **Фаза 3 (Спад):** Тригер розмикається, ШІМ плавно гаситься протягом 100 мс.

## 🔌 Схема підключення (Wiring Diagram)

Зв'язок між керуючим модулем (ESP32-C3) та виконавчим вузлом (Wemos D1 Mini) реалізовано через ізольовані програмні порти UART. Оскільки обидва мікроконтролери працюють з логічними рівнями 3.3V, додаткові дільники напруги не потрібні.

[ ESP32-C3 Пульт ]                             [ Wemos D1 Mini (VRX Node) ]
+------------------+                           +----------------------------+
|                  |                           |                            |
|        GPIO 4 TX |-------------------------->| D3 (GPIO0) RX (SoftSerial) |
|        GPIO 3 RX |<--------------------------| D4 (GPIO2) TX (SoftSerial) |
|              GND |<------------------------->| GND (Спільна земля)        |
+------------------+                           +----------------------------+
|
+------------------+------------------+
|                                     |
v                                     v
[ Матриця Оптопар ]                  [ Walksnail VRX ]
+-------------------+                +------------------+
| D1 -> VTL5C3 PWM  |                |                  |
| D0 -> PC817 Trig  |--------------->| Лінія DATA       |
| D2 -> PC817 Bind  |--------------->| Лінія BIND       |
+-------------------+                +------------------+


### Важливі зауваження щодо монтажу:
1. **Спільна земля (GND):** Землі обох плат та аналогової частини Walksnail VRX обов'язково мають бути об'єднані в одну точку.
2. **Довжина дротів:** Для лінії зв'язку між ESP32-C3 та D1 Mini (понад 2-3 метри) рекомендується використовувати екрановану виту пару для захисту від зовнішніх наведень.
